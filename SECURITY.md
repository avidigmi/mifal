# Security

Mifal writes into your home folder and wires instructions into your coding agents, so a flaw in what it writes, keeps or removes matters.

Report a vulnerability privately through [GitHub's private vulnerability reporting](https://github.com/romiluz13/mifal/security/advisories/new), not in a public issue. Include the Mifal version (`cat ~/.agents/mifal/VERSION`), your macOS and Python versions, and the smallest steps that reproduce it in a disposable home folder.

Supported: the latest release on `main`. Mifal is alpha; fixes go into the next release rather than being backported.
