# Discover the documentation

Read [DDD](../ddd/SKILL.md) and apply **Inspect the task and its surroundings**,
**Research the questions that matter**, and the persistent-note rules in step 3.
That skill owns the procedure.

Finish with concrete questions, applicable sources and versions, important rules,
and unresolved gaps saved in the existing plan or one task note. For discovery-
only work, stop before implementation planning or application edits. If the user
authorized the whole task, continue through DDD.

Use [where to look](references/stack-detection.md) and
[source retrieval](references/adapters.md) when needed. No CLI setup is required.

Find the documentation entry point and relevant application explanations during
inspection; check applicability before expanding research.
