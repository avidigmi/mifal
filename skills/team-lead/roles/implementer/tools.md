# Tool expectations — implementer

Expected for this role:

- **Editor + shell** — the daily drivers
- **The project's test runner** — you run the checks your brief's claims name
- **git** — your Result section anchors claims to commits

Before starting:

1. `python3 ~/.agents/skills/team-lead/stewardship/steward.py ledger show`
   — the lead's picture of everyone's MCPs/connectors; find your own row in
   the output.
2. If the brief names a tool you lack (a database MCP, a connector), ring
   `HELP <task> missing tool <name>` before starting — the lead checks the
   ledger before briefing, but drift happens.

After finishing: the return's tool ledger section lists skills and MCPs
used, considered, and rejected, with reasons — it feeds the stewardship
registries.
