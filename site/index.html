Agents say done. Mifal asks for the evidence.

A gate that says no.

validate_contracts.py checks a brief before it is sent, a receipt before it is accepted, and a phase record before the next phase starts. A record missing its evidence is refused, and the refusal names the fix.

The Guide tells every agent to run it at each gate. Whether it does is up to the agent. On a team, the team lead skill has the lead run it on every return before accepting the work.

One route, in order.

Each agent's rules file gets the same Guide. It loads Matt Pocock's engineering workflow before any engineering request. A build that spans several sessions runs through these phases, with a gate between each.

  1. Scope

    Name the work and pick its route.

  2. Grill

    A relentless interview until the plan holds.

  3. Spec

    Write down what done means.

  4. Tickets

    Thin vertical slices with their blocking edges.

  5. Implement

    Slice by slice, tests first.

  6. Review

    Standards and spec, by an agent that did not write it.

  7. Retro

    What changes next time.

A build that fits one session goes from the grill straight to implement, test first, then review. Research, planning, debugging and review requests take shorter routes. For a team, the team lead skill briefs agents in Herdr panes, checks their receipts and sends work to a reviewer before accepting it.

Install it, check it, take it out.

This is a real run of Mifal 0.1.1 in a disposable home folder. The install writes only what the dry run listed. mifal doctor checks the wiring: every rules file carries the Guide, and the 39 skills are in place.

mifal uninstall removes every file, link and block Mifal wrote, restores what it moved aside, and keeps any file you edited. Herdr stays installed.

The final comparison is against a snapshot of the home folder taken before the install. It leaves out the working folder holding the clone and the .cache and .npm caches, and Herdr was already installed.

What is checked, and what is not.

A program can refuse a record. It cannot make an agent write one. Mifal keeps that line visible.

Checked by a program, every time it runs

  • What the installer, update and uninstall write, what they keep, and how they roll back, with the Manifest as the record.
  • The install's files, links and blocks, the validator's own self-check, Herdr, and the agent-browser CLI, through mifal doctor.
  • A brief, a receipt or a phase record, when the agent or the lead runs the validator.

Relies on the agent following the Guide

  • Reading the engineering workflow and loading the skill for each phase.
  • Running the validator at each gate, and asking you before cutting a step.
  • Reporting only what its evidence shows. Treat a session's claims as claims until you see the evidence they cite.

Alpha, and honest about it.

The installer, update, uninstall, doctor and validator are covered by tests on Python 3.9 and 3.13 on macOS.
